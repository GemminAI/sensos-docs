# Changelog

All notable changes to the SensOS Developer Portal (`GemminAI/sensos-docs`) are documented here.

The format follows Keep a Changelog principles. Versioning uses a documentation channel model for early releases (`0.x` Developer Preview).

## [0.1.0] — 2026-07-26

### Added

- Astro-based documentation portal for https://sensos.org
- RFC series with metadata, Prev/Next, related RFCs, GitHub edit/download links
- Architecture stack diagram and interactive L0–L7 layer graph
- Products and repository documentation pages
- Governance page anchored on RFC-NVS-GOV-0001
- Graph Explorer with GraphProvider abstraction (GraphifyProvider + seed catalog)
- Compliance dashboard consuming `/compliance/index.json`
- Machine APIs under `/api/v1/rfc`, `/api/v1/products`, `/api/v1/graph`
- Dark mode, responsive layout, skip link, Open Graph / Twitter metadata
- `robots.txt`, sitemap, CNAME for GitHub Pages custom domain
- Custom 404 page
