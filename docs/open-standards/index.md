SensOS is an **open interoperability platform** with a proprietary reference implementation.

Anyone may build software that speaks SensOS interfaces. Public RFCs define those interfaces. Gemmina Intelligence retains the right to innovate privately on implementation quality, performance, and product experience.

## How the ecosystem works

1. **Read the Charter** — why standards are public and what they promise.
2. **Browse Public RFCs** — stable interfaces, behavior, guarantees, and conformance.
3. **Run conformance tests** — prove Compatible behavior against the published suite.
4. **Seek certification** — optional official validation for partners and enterprises.

## Who this is for

| Audience | What you get |
| --- | --- |
| Developers | Stable ABIs and lifecycle contracts without vendor lock-in theater |
| Partners | Clear integration surfaces and conformance gates |
| Enterprises | Audit-friendly standards plus optional Enterprise certification |
| Researchers | Public behavioral contracts suitable for reproducible study |
| Vendors | A level field for compatible products and competing implementations |

## The boundary that protects the ecosystem

| Public (open) | Not public |
| --- | --- |
| Interfaces | Internal algorithms |
| Observable behavior | Optimizations |
| Guarantees | Runtime proprietary techniques |
| Conformance | Product internals |
| Compatibility | Trade-secret evaluation methods |

Open standards create a market. Proprietary excellence creates differentiation. SensOS is designed for both.
