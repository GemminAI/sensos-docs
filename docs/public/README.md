# Public documentation tier

Content in this tier (and `docs/rfc/` public contracts) may appear on **sensos.org**.

## Allowed

- Product messaging and value propositions
- Public RFC contracts: WHAT, ABI, lifecycle, guarantees, conformance
- Open standards philosophy
- Developer onboarding that does not disclose proprietary mechanisms

## Forbidden

- Algorithms, calibration, optimization, wire layouts, token grammar
- Kernel internals, schedulers, roadmaps, experiment IDs
- Partner/Enterprise/Internal/Trade-secret material

See also: `RFC_PHILOSOPHY.md`, `INFORMATION_ARCHITECTURE.md`.
