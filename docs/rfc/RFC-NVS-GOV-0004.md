## Abstract

This RFC adopts the SensOS Conformance Program and Certification Program designs, establishing Compatible, Certified, and Enterprise Certified claim levels.

## Normative references

- **[Conformance Program](/Open-Standards/Conformance)** — `docs/open-standards/conformance.md`
- **[Certification](/Open-Standards/Certification)** — `docs/open-standards/certification.md`

## Claim levels (summary)

| Claim | Meaning |
| --- | --- |
| SensOS Compatible | Required public CTS pass for a declared profile |
| SensOS Certified | Official validation by Gemmina Intelligence |
| SensOS Enterprise Certified | Production and enterprise security validation |

## Normative keywords

The key words **MUST**, **MUST NOT**, **SHOULD**, **SHOULD NOT**, and **MAY** are to be interpreted as described in RFC 2119 and RFC 8174 when written in uppercase.
