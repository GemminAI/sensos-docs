## Abstract

This RFC adopts the RFC Classification Policy governing Classification, Status, Audience, and Normative Level for all SensOS RFC publications and access-controlled companions.

## Normative reference

**[RFC Classification Policy](/Open-Standards/Classification)**

Canonical Markdown: `docs/open-standards/classification.md`

## Required fields (summary)

Every RFC SHALL declare Classification, Status, Audience, and Normative Level consistent with the policy.

## Normative keywords

The key words **MUST**, **MUST NOT**, **SHOULD**, **SHOULD NOT**, and **MAY** are to be interpreted as described in RFC 2119 and RFC 8174 when written in uppercase.
