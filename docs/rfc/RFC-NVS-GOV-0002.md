## Abstract

This RFC adopts the SensOS Open Standards Charter as a Best Current Practice for the public standards program: interoperability is open, interfaces are stable, and implementations remain free to innovate privately.

## Normative reference

The full Charter text is published at:

**[SensOS Open Standards Charter](/Open-Standards/Charter)**

Canonical Markdown: `docs/open-standards/charter.md`

## Public commitment (summary)

Public RFCs define interfaces, behavior, guarantees, conformance, and compatibility.  
Public RFCs do not define internal algorithms, optimizations, runtime implementations, proprietary techniques, or product internals.

## Normative keywords

The key words **MUST**, **MUST NOT**, **SHOULD**, **SHOULD NOT**, and **MAY** are to be interpreted as described in RFC 2119 and RFC 8174 when written in uppercase.
