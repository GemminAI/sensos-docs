# RFC Series

Normative and procedural specifications for the SensOS ecosystem.

This portal publishes RFCs under a **portal number space** (`RFC-NNNN`). Each page records provenance when it consolidates prior identifiers (for example `RFC-NVS-0100` or `RFC-OBS000`).

## Lifecycle

See [RFC_MAP](RFC_MAP.md) for the authoritative lifecycle:

`Draft → Accepted → Planned → Partial → Implemented → CI Verified → Released`

## Page template

Every RFC page in this portal includes:

1. Status
2. Version
3. Last Updated
4. Abstract
5. Specification
6. Reference Implementation
7. Related RFCs

## Contribution

1. Open a PR against [sensos-docs](https://github.com/GemminAI/sensos-docs).
2. Update [RFC_MAP](RFC_MAP.md) when proposing a lifecycle transition.
3. Do not silently renumber identifiers — record provenance in the Abstract or Specification.
