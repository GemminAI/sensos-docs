# RFC-0200: Observation ABI

| Field | Value |
|---|---|
| **Status** | Partial |
| **Version** | 1.0.0 |
| **Last Updated** | 2026-07-26 |
| **Series** | Runtime ABI (portal 02xx) |
| **Provenance** | Portal consolidation of `RFC-OBS000` Observation ABI (AMS-0001) |

## Abstract

Defines the **sole public data contract** of the SensOS Observation Layer.

Pillar: **Data, not meaning** — observations and annotations are structured payloads. Downstream engines MUST NOT require Observation Layer internals beyond this ABI.

Architectural migration (AMS-0001): Observation standardization and annotation are owned by the Observation Layer; Projection engines consume `AnnotatedObservation` only.

## Specification

### 1. Governed types

| Type | Role |
|---|---|
| `Observation` | Normalized observation payload |
| `ObservationSource` | Provenance of the observation producer |
| `Annotation` | Annotation payload attached by the Observation Layer |
| `AnnotatedObservation` | Sole handoff object to Projection and later stages |

### 2. Responsibility migration (AMS-0001)

```text
Reality → ObservationSource(s)
                ↓
        Observation Layer  (this RFC)
                ↓  AnnotatedObservation
        Projection Engine  (RFC-0201)
                ↓
        Knowledge / Universe ABIs (future; HEKB boundary via RFC-0203)
```

**MUST**

- Projection and later stages depend only on this ABI for observation input
- Observation Layer MUST NOT embed ProjectionProvider algorithms

**MUST NOT**

- Treat taxonomy / chart assignment as a required Observation field for CORE consumers unless an extension RFC says otherwise
- Collapse Observation and Projection into a single ownership domain

### 3. Non-goals

- Transport protocols
- Internal annotator model weights / prompts
- Authentication / authorization
- Broad HEKB world-model schemas

### 4. Constitutional compliance

| Item | Statement |
|---|---|
| Applicable principles | Observation-centered intelligence; reality before narrative |
| Normative references | RFC-0000; RFC-0001; RFC-0201 |
| Responsibility boundary | Owns observation wire/data contracts only |
