# Enterprise documentation tier

Controlled materials for customers and security reviews under commercial agreement.

## Typical contents

- Deployment guides (without trade-secret internals)
- Security whitepapers and shared-responsibility models
- Audit/compliance mapping
- SLA / support runbooks
- Redacted architecture for diligence

## Rule

Enterprise docs may be deeper than Public, but MUST NOT include Trade Secret execution methods unless a separate exhibit explicitly authorizes it.
